# Автомойка — доработка конфигурации 1С

Разбор выгрузки информационной базы (`.dt`) и код для доработки.

В базе нет ни одного программного модуля: документы ничего не проводят, для материалов нет регистра остатков.

## Что сделать в Конфигураторе

1. **Регистр накопления `ОстаткиМатериалов`** (новый):
   - вид регистра: **Остатки**;
   - измерение `Материал` с типом `СправочникСсылка.Материалы`;
   - ресурсы `Количество` (Число 15,3) и `Сумма` (Число 15,2).
2. **Регистр `Выручка`**: вид регистра — **Обороты**. На закладке «Регистраторы» отметить документ `Оплата`.
3. **Документ `Оплата`** → закладка «Движения»: отметить регистр `Выручка`. На закладке «Ввод на основании» выбрать «Вводится на основании» → `ЗаказНаМойку`.
4. **Документы `ПоступлениеТоваров` и `СписаниеМатериалов`** → закладка «Движения»: отметить регистр `ОстаткиМатериалов`.
5. Вставить код из папки `Модули/` в соответствующие модули (ПКМ по документу → «Открыть модуль объекта» или «Форма документа» → «Модуль»).
   - В форме `ЗаказНаМойку` привязать обработчики к событиям колонок таблицы (список в начале файла модуля формы).
6. Выполнить **F7** (обновить конфигурацию базы данных) и проверить работу.

## Логика

- **Заказ на мойку**: выбор услуги подставляет цену из `ЦеныУслуг` (срез последних; если цены нет — из справочника), считает суммы строк и итог. При создании ставится статус «Новый». Регистры документ не двигает.
- **Оплата**: вводится на основании заказа (подставляются клиент, вид оплаты и сумма) и при проведении записывает приход в `Выручка`.
- **Поступление товаров**: проводит приход в `ОстаткиМатериалов`.
- **Списание материалов**: проводит расход и не даст провести документ, если материала не хватает.
