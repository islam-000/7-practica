# Автомойка — конфигурация 1С (выгрузка в файлы XML)

Платформа 8.3.27, формат выгрузки 2.20. Папка `Автомойка_XML` — конфигурация целиком.

## Как загрузить

1. Откройте пустую базу в **Конфигураторе**.
2. **Конфигурация → Открыть конфигурацию**.
3. **Конфигурация → Загрузить конфигурацию из файлов…** → укажите папку `Автомойка_XML` → «Загрузить».
4. **F7** (Обновить конфигурацию базы данных) → «Принять».
5. Запустите **1С:Предприятие** — слева появится раздел «Автомойка».

## Состав

- **Справочники:** Клиенты, Автомобили, Услуги, Сотрудники, Материалы, Боксы.
- **Документы:** Заказ на мойку, Оплата, Поступление товаров, Списание материалов.
- **Перечисления:** Пол, Тип автомобиля, Статус сотрудника, Статус заказа, Вид оплаты.
- **Регистр сведений:** Цены услуг.
- **Регистры накопления:** Выручка (обороты), Остатки материалов (остатки).
- **Подсистема:** Автомойка (все объекты в одном разделе).

## Логика

- **Заказ на мойку** — при записи сам подставляет цены услуг (из «Цен услуг», иначе из справочника) и считает суммы.
  При проведении списывает материалы, если у услуги указан «Используемый материал» и «Расход материала на услугу».
- **Оплата** — вводится кнопкой «Создать на основании» из заказа, проводит выручку и ставит заказу статус «Выдан».
- **Поступление товаров** — приход материалов.
- **Списание материалов** — расход с проверкой остатка (не проведётся, если материала не хватает).

## Отличия от старой базы

- Исправлены названия реквизитов: `Коментарии` → `Комментарий`, `Ответсвенный` → `Ответственный`,
  в заказе `Автомобили` → `Автомобиль`, `Сотрудники` → `Мойщик`.
- ФИО клиента/сотрудника — это стандартное поле «Наименование» (до 100 символов).
- Увеличены слишком короткие строки (марка, модель, должность, причина, поставщик).
- В услугу добавлен реквизит «Расход материала на услугу».
