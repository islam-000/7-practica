# Сайт по макету из Figma

Статичный лендинг: `index.html` + `css/style.css` + `js/main.js`. Сборка не нужна — просто откройте `index.html` в браузере.

## Фото из макета

Бутылки, лёд, пузырьки, автомат, росток и контейнер нарисованы на SVG/CSS, поэтому сайт выглядит цельно и без картинок.
Чтобы поставить фото из Figma, экспортируйте их и положите в `assets/` с этими именами — они подхватятся автоматически:

| Файл                 | Где используется                         |
|----------------------|-------------------------------------------|
| `assets/pick-1.jpg`  | карточка «Обновлённый вкус»               |
| `assets/pick-2.jpg`  | карточка «Топ-5 мест для фото»            |
| `assets/pick-3.jpg`  | карточка «Акция: больше вкуса»            |
| `assets/pick-4.jpg`  | карточка «Набор для лета»                 |
| `assets/history.jpg` | винтажное фото в блоке «История»          |
| `assets/lineup.jpg`  | ряд бутылок в блоке «История»             |
| `assets/eco.jpg`     | фон блока «Устойчивое развитие»           |
| `assets/recycle.jpg` | фото контейнера для переработки           |
