# Сайт по макету из Figma

Статичный лендинг: `index.html` + `css/style.css` + `js/main.js`. Сборка не нужна — просто откройте `index.html` в браузере.

## Блоки

Прелоадер с крышкой → первый экран → бегущая строка → «Легендарный напиток» → цифры →
каталог вкусов → интерактивный выбор вкуса (цвет фона, состав) → бутылка с именем (конструктор) →
«То, что цепляет» → история и карусель эпох → идеальная подача → устойчивое развитие →
цикл переработки → галерея моментов → подписка → подвал. Плюс прогресс-бар прокрутки,
кнопка «наверх» в виде крышки, «шипучие» пузырьки при клике на кнопки.

## Фото из макета

Бутылки, лёд, пузырьки, автомат, росток и контейнер нарисованы на SVG/CSS, поэтому сайт выглядит цельно и без картинок.
Чтобы поставить фото из Figma, экспортируйте их и положите в `assets/` с этими именами — они подхватятся автоматически:

| Файл                 | Где используется                         |
|----------------------|-------------------------------------------|
| `assets/pick-1.jpg`  | карточка «Обновлённый вкус»               |
| `assets/pick-2.jpg`  | карточка «Топ-5 мест для фото»            |
| `assets/pick-3.jpg`  | карточка «Акция: больше вкуса»            |
| `assets/pick-4.jpg`  | карточка «Набор для лета»                 |
| `assets/history.jpg` | винтажное фото в блоке «История»          |
| `assets/lineup.jpg`  | ряд бутылок в блоке «История»             |
| `assets/eco.jpg`     | фон блока «Устойчивое развитие»           |
| `assets/recycle.jpg` | фото контейнера для переработки           |
| `assets/moment-1.jpg` … `moment-5.jpg` | плитки галереи «Моменты, которыми делятся» |

## Логотип

Все файлы в `assets/logo/`, надписи переведены в кривые — шрифты для них не нужны.

| Файл | Что это |
|------|---------|
| `logo.svg` / `.png` | основной горизонтальный: эмблема + надпись, для светлого фона |
| `logo-white.svg` / `.png` | одноцветный белый, для красного фона |
| `logo-dark.svg` / `.png` | для тёмного фона |
| `logo-stacked.svg` / `.png` | вертикальный: эмблема над надписью |
| `logo-mark.svg` / `.png` | только эмблема (аватарка, иконка приложения) |
| `logo-mark-white.svg` / `.png` | эмблема, белая версия |
| `wordmark-white.svg` | только надпись, белая — используется в шапке сайта |
| `favicon.svg` | иконка вкладки браузера |

SVG можно перетащить прямо в Figma — каждая буква и деталь будет отдельным редактируемым векторным слоем.
